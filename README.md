# AAAT — Adaptive Accessible Tutor (Version 3)

Free static website prototype for the AI Tennessee Challenge. Open `index.html` locally or publish it using GitHub Pages.

## What's included
- Five grade bands covering K–12
- Mathematics, English Language Arts, Science, Social Studies, Computer Science, Engineering & CTE
- Eight demonstration topic pathways
- Four-question untimed checks with challenge level updated from answer correctness and self-reported comfort
- Lessons at three reading/complexity levels, browser speech, reading spacing and tints
- Local-only progress, optional standards-framework references, and links to official Tennessee standards

## Important limits
This is a prototype. It does not provide complete K–12 curriculum coverage or verified standard-by-standard alignment. The tutor is rule-based, not a connected AI model. Some interface translations are partial and lesson content remains in English. Questions are samples, not validated measures of student proficiency. Progress is stored in localStorage and may be visible to other people using the same browser profile. Avoid entering identifiable student data.

## Publish free on GitHub Pages
1. Create a public GitHub repository, e.g. `aaat-tutor`.
2. Upload `index.html` to the repository root.
3. In Settings > Pages choose Deploy from a branch, main, /(root).
4. Open the URL GitHub provides. This prototype requires no server, API key, or paid hosting.

## Standards
Source: https://www.tn.gov/education/districts/academic-standards.html
The official Tennessee standards change on implementation schedules. Confirm exact grade/course benchmark codes and wording before making any alignment claims. The standards selector is a reference, not a verified standards mapping.

## Student ownership and testing
Students should review the implementation, document their design decisions, test with volunteers using anonymous feedback, and disclose the assistance received from AI tools. Do not use this as a disability screening or special education evaluation.
